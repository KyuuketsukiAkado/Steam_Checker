# Steam Wrapped · repro4chful

Одностраничная статистика Steam-профиля: часы, топ игр, жанры, бэклог-рулетка
и генератор PNG-карточки. Чистые HTML/CSS/JS без фреймворков, сборки и CDN —
страница целиком статическая и живёт на GitHub Pages.

**Живая версия:** https://kyuuketsukiakado.github.io/Steam_Checker/

---

## Что внутри

| Блок | Что показывает |
|---|---|
| Шапка | ник, аватар и три главные цифры: игр в библиотеке, часов всего, часов за 2 недели |
| 01 · Главная игра жизни | игра с максимумом часов + пересчёты: дни нон-стоп, рабочие месяцы, % года, километры пешком |
| 02 · Топ игр | горизонтальные бары по часам, длина — доля от лидера |
| 03 · Чем занимаюсь сейчас | активность за последние две недели |
| 04 · Вкус по жанрам | донат на SVG с интерактивной легендой |
| 05 · Судьба вечера | кнопка вытягивает 3 случайные незапущенные игры из бэклога |
| 06 · Карточка | PNG 1080×1350 рисуется на canvas прямо в браузере |

## Стек

Ноль зависимостей: HTML, CSS (кастомные свойства, grid, `IntersectionObserver`),
ванильный JS. Шрифты **Unbounded** и **Manrope** (variable, OFL) лежат
локально в `assets/fonts` — внешних запросов страница не делает вообще.

## Структура

```
index.html                  разметка
assets/css/style.css        тема, типографика, сетка
assets/js/app.js            вся логика: счётчики, бары, донат, рулетка, canvas
assets/js/data.js           данные (генерируется скриптом)
assets/js/data.sample.js    образцовые данные для отката
assets/fonts/               Unbounded + Manrope (woff2) и лицензии
assets/img/avatar.jpg       аватар, скачивается скриптом
fetch_data.py               сбор данных из Steam Web API
tools/selftest.py           офлайн-проверка скрипта на моках
ИНСТРУКЦИЯ.md               пошаговое руководство по запуску
```

## Обновить данные

```bash
echo "КЛЮЧ_С_steamcommunity.com/dev/apikey" > steam_key.txt
python3 fetch_data.py --user repro4chful
```

Скрипт резолвит ник в SteamID64, забирает библиотеку и активность через
Steam Web API, добирает жанры из store-эндпоинта `appdetails` (неофициальный,
поэтому с паузами, ретраями и файловым кэшем в `.cache/`), качает аватар и
перезаписывает `assets/js/data.js`.

Полезные флаги: `--dry-run`, `--steamid`, `--delay 3`, `--max-details 200`,
`--refresh-genres`. Подробности и разбор ошибок — в [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

Проверить скрипт без ключа и интернета: `python3 tools/selftest.py`.

## Локальный просмотр

```bash
python3 -m http.server 8000   # → http://localhost:8000
```

## Безопасность

Ключ API читается из `steam_key.txt`, который прописан в `.gitignore` и в
репозиторий не попадает. В `data.js` уезжают только публичные данные профиля:
названия игр, часы и жанры.
