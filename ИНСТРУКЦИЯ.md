# ИНСТРУКЦИЯ: как обновить данные Steam

Читай сверху вниз и делай ровно то, что написано. Ничего сломать нельзя — все
файлы лежат в git, любой шаг откатывается.

**Всего 5 шагов, минут 20, из них 5 минут просто ждать.**

---

## Шаг 0. Что вообще происходит

Страница уже живёт на настоящих цифрах (я собрала их руками). Но аватар
скачает только скрипт, и однажды захочется свежих данных — например, когда
Slay the Spire 2 обгонит Dota. Ходить в Steam будет `fetch_data.py`.
Я запустить его не могу — у меня из песочницы нет интернета до Steam.
Поэтому запускаешь ты, на своём компьютере.

Тебе нужно:
1. получить ключ доступа к Steam API (бесплатно, 2 минуты);
2. открыть профиль (иначе Steam не отдаст библиотеку);
3. скачать проект на компьютер;
4. запустить одну команду;
5. запушить результат.

---

## Шаг 1. Получить ключ Steam API

1. Открой в браузере: **https://steamcommunity.com/dev/apikey**
2. Залогинься под своим аккаунтом, если попросит.
3. В поле **Domain Name** напиши что угодно, например: `localhost`
   (это формальность, никто это поле не проверяет).
4. Поставь галочку согласия и нажми **Register**.
5. Появится строка **Key: ABCD1234...** — это 32 символа букв и цифр.
   **Скопируй её.** Никому не показывай, мне в чат тоже не присылай.

> Если Steam пишет, что ключ недоступен — обычно нужно, чтобы на аккаунте была
> хоть одна покупка на $5+. У тебя 324 игры, так что всё ок.

---

## Шаг 2. Открыть игровые данные в профиле

Steam по умолчанию прячет библиотеку даже от тебя самой через API.

1. Steam → клик по нику вверху справа → **Профиль**.
2. Кнопка **Редактировать профиль** → слева **Настройки приватности**.
3. Найди пункт **«Игровые данные: подробности»** (Game details).
4. Поставь **«Открытый»** (Public).
5. Ниже есть галочка **«Всегда скрывать моё игровое время»** — она должна быть
   **снята**, иначе часы приедут нулями.
6. Настройки сохраняются сами. Можешь вернуть приватность обратно сразу после
   того, как отработает скрипт.

## Шаг 3. Скачать проект на компьютер

Репозиторий теперь называется `steam-wrapped`, данные уже настоящие —
нужна ветка `master`.

### Вариант А — через git (правильный, рекомендую)

Открой терминал:
* **Windows:** меню Пуск → напиши `cmd` → Enter.
* **macOS:** Cmd+Space → напиши `Terminal` → Enter.

Вставляй команды по одной, после каждой — Enter:

```
cd Desktop
git clone https://github.com/KyuuketsukiAkado/steam-wrapped.git
cd steam-wrapped
```

> Если у тебя уже лежит старая копия (из времён `Steam_Checker`) — проще
> склонировать заново: в старой копии другая история изменений.

> Если пишет `git: команда не найдена` — поставь Git с https://git-scm.com/downloads,
> при установке жми «Далее» на всех экранах. Потом закрой терминал, открой заново
> и повтори команды.

### Вариант Б — просто скачать zip (если git не хочется)

1. Открой https://github.com/KyuuketsukiAkado/steam-wrapped
2. Зелёная кнопка **Code** → **Download ZIP**.
3. Распакуй архив на рабочий стол.
4. Учти: с zip-вариантом результат придётся закидывать обратно руками (см. шаг 5Б).

## Шаг 4. Положить ключ и запустить скрипт

### 4.1. Проверь, что есть Python

В терминале набери:

```
python --version
```

Должно ответить `Python 3.8` или выше (например `Python 3.12.1`).

* Если пишет `Python 2.7` — попробуй `python3 --version`, и дальше везде вместо
  `python` пиши `python3`.
* Если пишет «не является внутренней или внешней командой» / `command not found` —
  ставь Python с https://www.python.org/downloads/ и **обязательно поставь галочку
  «Add Python to PATH»** на первом экране установщика. Потом закрой терминал,
  открой заново.

### 4.2. Зайди в папку проекта

```
cd Desktop
cd steam-wrapped
```

Проверить, что ты в нужном месте: набери `dir` (Windows) или `ls` (macOS).
В списке должны быть `index.html`, `fetch_data.py`, `assets`, `extra_games.json`.

### 4.3. Создай файл с ключом

Файл должен называться **steam_key.txt**, лежать рядом с `index.html`,
и внутри — только ключ, одной строкой, без пробелов и кавычек.

**Способ мышкой (проще всего):**
1. Открой папку `steam-wrapped` в проводнике.
2. Правый клик → Создать → Текстовый документ.
3. Назови его ровно `steam_key.txt`
   (Windows может прятать расширения — тогда файл выйдет `steam_key.txt.txt`.
   Чтобы проверить: Проводник → вкладка «Вид» → галочка «Расширения имён файлов».)
4. Открой его блокнотом, вставь ключ, сохрани, закрой.

**Способ командой (Windows):**
```
echo ТВОЙ_КЛЮЧ_СЮДА> steam_key.txt
```
**Способ командой (macOS):**
```
echo "ТВОЙ_КЛЮЧ_СЮДА" > steam_key.txt
```

> Этот файл уже прописан в `.gitignore` — в GitHub он не уедет никогда.
> Проверить можно командой `git status`: `steam_key.txt` не должен появляться в списке.

### 4.4. Пробный запуск (ничего не меняет)

```
python fetch_data.py --user K_Ak4d0 --dry-run
```

Скрипт сходит в Steam и просто покажет цифры, файлы не тронет. Первый прогон
~5 минут: он ходит за жанрами по одной игре с паузой, чтобы Steam не обиделся.

Должно вывести примерно такое:

```
· ключ прочитан (…a4f1)
· SteamID64: 76561198...
· профиль: mormyszka
· игр в библиотеке: 324
· игр за 2 недели: 4
· extra_games.json: +1 (Dota 2)
· аватар: assets/img/avatar.jpg
· тяну жанры для 180 игр (кэш: .cache/appdetails)
· отсечён служебный софт и тестовые ветки: N
    10/180
    ...
  ИТОГО
  игр:            324
  часов всего:    8XXX
  часов за 2 нед: 94
  не запускала:   68
  игра жизни:     Dota 2 — 2848.8 ч
```

Строка `extra_games.json: +1 (Dota 2)` обязательна — без неё Dota 2
потеряется: магазин держит её в игнор-листе и API не отдаёт.

**Если цифры похожи на правду — отлично, иди дальше.**

### 4.5. Боевой запуск

Та же команда, но без `--dry-run`:

```
python fetch_data.py --user K_Ak4d0
```

Второй раз он отработает быстро — жанры уже в кэше. В конце напишет
`· записан assets/js/data.js`.

### 4.6. Посмотри результат своими глазами

```
python -m http.server 8000
```

Открой в браузере **http://localhost:8000** — там твоя страница на свежих
данных, с аватаром. Чтобы остановить сервер, нажми в терминале **Ctrl+C**.

## Шаг 5. Отправить результат в репозиторий

### Вариант А — через git (если делала шаг 3 вариантом А)

```
git add assets/js/data.js assets/img/avatar.jpg
git commit -m "data: свежие данные Steam + аватар"
git push origin master
```

Если попросит логин — введи имя пользователя GitHub, а вместо пароля нужен токен:
GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
→ Generate new token → галочка `repo` → скопировать и вставить в терминал.
(Пароль от GitHub там уже не работает, это нормально.)

### Вариант Б — руками (если качала zip)

Открой файл `assets/js/data.js`, скопируй всё содержимое и пришли мне в чат.
Он большой, но текстовый — ничего секретного там нет, ключа внутри нет.
Аватар просто перетащи в чат файлом — я вставлю.

## Если что-то пошло не так

| Что видишь | Что делать |
|---|---|
| `Нет ключа` | Файла `steam_key.txt` нет или он не в той папке. Проверь `dir` / `ls`. |
| `Не удалось найти профиль «K_Ak4d0»` | Запусти с ID: сначала узнай его на https://steamid.io (вставь ссылку на профиль, возьми **steamID64**), потом `python fetch_data.py --steamid 76561198...` |
| `API вернул пустую библиотеку` | Не сделан шаг 2 — приватность. Открой игровые данные, подожди минуту, повтори. |
| Часы приехали нулями | В настройках приватности стоит галочка «скрывать игровое время». Сними. |
| В топе нет Dota 2 | Проверь, что рядом со скриптом лежит `extra_games.json` (он в репо). |
| Много строк `! HTTP 429` | Steam просит помедленнее. Прерви (Ctrl+C) и запусти с `--delay 3`. Прогресс не потеряется — жанры сохраняются в кэш. |
| Скрипт идёт вечность | Так и должно быть в первый раз (~5 мин на 180 игр). Можно ускорить: `--max-details 60`. |
| Всё сломалось, хочу как было | `git checkout assets/js/data.js` — вернётся версия из репо. |
| Windows ругается на кодировку | Выполни в терминале `chcp 65001` и запусти скрипт заново. |

## Шаг 6. Автообновление: чтобы не запускать руками вообще

Всё, что описано выше, GitHub теперь умеет делать сам — раз в сутки.
Настроить нужно **один раз**, дальше оно работает без тебя.

### 6.1. Положить ключ в секреты (один раз)

Ключ нельзя просто вписать в файл — репозиторий публичный. Для этого
у GitHub есть «секреты»: их видят только запуски, но не люди.

1. Открой репозиторий на GitHub.
2. Сверху вкладка **Settings** (шестерёнка, справа в ряду вкладок).
3. Слева в меню: **Secrets and variables** → **Actions**.
4. Зелёная кнопка **New repository secret**.
5. Поле **Name** — впиши ровно: `STEAM_API_KEY`
6. Поле **Secret** — вставь сам ключ (тот же, что в `steam_key.txt`).
7. **Add secret**.

Всё. Ключ спрятан, увидеть его обратно нельзя даже тебе — только заменить.

> `steam_key.txt` на компьютере оставь, он никуда не делся: скрипт по-прежнему
> берёт ключ оттуда, когда ты запускаешь его руками.

### 6.2. Как это работает дальше

Заходишь в репозиторий, сверху вкладка **Actions**. Слева два пункта:

**«Обновить мою статистику»** — запускается сам каждую ночь в 04:20 UTC
(07:20 по Минску). Тянет свежие данные, перерисовывает og-картинку и делает
коммит — но только если цифры реально изменились. Можно запустить и руками:
выбрать слева, справа кнопка **Run workflow** → зелёная **Run workflow**.

**«Собрать карточку друга»** — только руками. Выбрать слева, **Run workflow**,
в появившееся поле вписать SteamID64 друга (или его ник, или ссылку на
профиль) и нажать зелёную кнопку. Через несколько минут в сводке запуска
появится ссылка вида:

```
https://kyuuketsukiakado.github.io/steam-wrapped/u/76561198…/
```

Её и отправляешь другу. Ему не нужно ничего устанавливать и не нужен свой
ключ — только его SteamID.

### 6.3. Если у друга «профиль закрыт»

Запуск покажет красную ошибку с текстом про приватность. Это не поломка —
Steam просто не отдаёт данные закрытых профилей. Другу нужно:

Steam → Профиль → **Настройки приватности** → «Игровые данные» =
**Открытый доступ**. Подождать пару минут и запустить workflow снова.

## Чего делать НЕ надо

* **Не присылай мне ключ** — ни в чат, ни в файле, ни скриншотом. Он мне не нужен.
* Не коммить `steam_key.txt` (он и так в `.gitignore`, но всё же).
* Не переименовывай папки `assets/` — страница ищет файлы по путям.
* Не редактируй `assets/js/data.js` руками — следующий запуск скрипта затрёт правки.
* **Не удаляй `assets/data/genres.json`** — это не мусорный кэш, а накопленный
  словарь жанров. Без него каждый запуск заново долбит магазин Steam и получает
  бан на час.
